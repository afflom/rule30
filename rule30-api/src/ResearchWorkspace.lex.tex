definition{
 name: contract,
 parameters: [],
 result: String,
 body: "Own a fresh detached Git worktree for one research request. Its full revision is immutable and its observed tree must equal the request library snapshot before a local library build. Tracked sources are checked again after the build before readiness. Existing paths are refused. Readiness grants an owned prepared workspace, never proof evidence. The caller owns the parent checkout and pinned tool environment. Repository paths must be absolute printable ASCII, which the admitted Host text adapter represents exactly. Cancellation drains pending host replies; uncertainty during creation or failed removal blocks reuse and retains recovery state. Only successful owned creation authorizes removal. A stopped or signalled tool has no normal exit code; its workspace is retained because direct-child cleanup does not establish descendant termination. Ready workspaces must be released after their candidate lifecycle ends.",
 axioms: [],
 executable: true
}
