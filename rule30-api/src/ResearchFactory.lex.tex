definition{
 name: contract,
 parameters: [],
 result: String,
 body: "The research factory plans the complete bounded cohort before any host effect. It checks every candidate source and returns all rejected serials together. One library obligation serves every attempt. Its input closure is the exact workspace configuration, snapshot and tool identities; candidate sources are separate downstream obligations. An owned ready library with that closure can be reused; an absent owner must be built; a changed, interrupted or released owner is blocked, never silently rebuilt or trusted. Factory readiness is not proof acceptance. Candidate verification, evidence retention and library cleanliness checks remain owned by the existing runner. No external pass receipt can establish readiness. No cross-run compiler verification cache or durable restart recovery is claimed.",
 axioms: [],
 executable: true
}
