 body: "Own one candidate attempt from exact-goal construction through verification and proof retention. Ordinary begin owns library checkout and release. beginPrepared borrows a ready library from a cohort and returns ownership to that cohort without removing it. Host replies and cancellation are the only inputs after begin. The session captures the same command and attestation reads the verifier consumes; no external receipt or checked answer can enter. A checked answer leaves the session only after exact evidence readback and completion of its project lifecycle. The cohort releases a borrowed library after all attempts finish. Failed archival of a checked proof retains its workspace for recovery. Cancellation drains outstanding replies.
