Retain that envelope and its library before atomically exchanging a journal reference against the exact predecessor blob. An empty predecessor requires absence. Identical successor and predecessor are refused, so replay cannot acquire the same transition twice. Only a normally exited successful owned Git update-ref emits committed. Readback or an existing identical record never substitutes for that acknowledgement. Cancellation drains the outstanding reply and never emits committed; uncertain execution retains state. A committed transition records a point in history, not a perpetual lease, descendant cleanup, proof acceptance, or claim publication. Enclosing recovery must allocate fresh workspaces, quarantine uncertain work and bound abandoned resources; publication must exchange against its own current predecessor.
