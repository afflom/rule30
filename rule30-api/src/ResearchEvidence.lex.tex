definition{
 name: contract,
 parameters: [],
 result: String,
 body: "Persist canonical evidence as a Git blob retained by a content-addressed ref. The caller owns the private record path and workspace; this component writes the exact record, hashes it locally, checks the stored blob before publication, retains the exact library commit under its own compare-and-swap ref and verifies that ref, creates the evidence ref with compare-and-swap against absence, and reads the published blob back byte for byte. An already published identical record is idempotent; another body or failed read is not success. Cancellation drains replies and supervises owned children. A blocked child or protocol failure retains recovery state. Storage is not proof verification: only the enclosing owned research session may promote verified evidence after persistence and workspace release.",

 executable: true
